# Pilot 09 · Menu iko wapi? · Website Action

**Choice:** one build, **Bongo Foodie**, to show how Altraware thinks about business websites. This is a portfolio/Reel for business owners considering a site. It is not a restaurant ad or a menu ordering guide. **One CTA:** comment **LINK** → the existing [Bongo Foodie website demo](https://bongofoodie.vercel.app/). Send the public site, never the owner review folder.

> Mteja akiuliza, menu iko wapi? Website yako ijibu kabla ya DM.

The design decision: put the action the visitor came for in view on the first screen. Use the real tap target, not a generic list of website features. In this example, **Explore the menu** → search `pilau` → photo, name and example price. Menu is a useful first answer even without proving checkout, delivery or sales.
