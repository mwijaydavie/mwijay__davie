# Tech Tip 01 · Evidence notebook · 18 Nov 2026

**Question:** For a stock lookup, when should I call the existing API directly and when should I add MCP? This follows [AI isome stoo](../pilots/06-agent-access.md). It is an explainer with a local test, not a new product integration, launch or usage trend.

| [MCP architecture, 2026-07-28](https://modelcontextprotocol.io/docs/2026-07-28/learn/architecture) and [Tools](https://modelcontextprotocol.io/specification/2026-07-28/server/tools) | A host uses a client to communicate with a server. Listing and calling tools are standardized (`tools/list`, `tools/call`). A server can wrap an HTTP API or another data source. Permissions and tool availability can depend on caller authorization; UI approval behavior is not automatically installed. |
