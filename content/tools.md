# Tool shortlist · kutoka brief hadi MP4

**Uamuzi wa pilot:** tumia IG kit uliyonayo kwa research na copy. Kwa video, **Remotion** kwa React/UI na captions; **Motion Canvas** pale code diff au diagram iliyopangwa kwa signals ndiyo somo. **HyperFrames** ni njia mbadala kwa HTML/GSAP, si dependency ya kuongezea Remotion. **HTML → PNG** kwa carousel. Huu ni uchaguzi kutokana na docs/READMEs tulizopitia 18 Nov 2026, si madai kwamba kila repo imeinstalliwa au kubenchmarked.

## Adoption gate

1. Hakiki upstream `LICENSE`/`NOTICE`, pin version au commit ya engine **moja**, na hakiki scripts kabla ya ku-run. Hatukuvendor package za GitHub wala kuendesha install snippets zao. Folder la `.agents/skills` lina skill yetu ya production.
2. Render preview ya scene ya pilot kwa 1080 × 1920 / 60 fps; kagua sample za kila beat, caption timing, sauti na media rights. Kama inafanya kazi, ndipo uweke dependencies na render script kwenye repo.
3. Mpaka umeona quality na throughput ya pilot, usiongeze queue server, paid API, publisher au MCP yenye write permissions.
