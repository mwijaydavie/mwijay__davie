# Payment Check · MALIPO

SW carousel, printable A4 worksheet and short Reel. [Editorial brief](../../content/pilots/05-payment-check.md) · [Captions and manual reply](../../content/pilots/05-payment-check-caption.txt).

`lab.mjs` replays trusted, synthetic events for one order. It does not accept requests or connect to a provider. No real money, external data, API keys or customer fields. `node --test` asserts five cases; matching, repeated events share one stored payment and one receipt after two deliveries. This model does not establish a provider integration, settlement, refund, reversal, concurrency, persistence, or statutory/fiscal receipt behavior. In production, use the provider contract, authenticate confirmations, and make the ledger and receipt write atomic and resistant to repeated events even across workers and restarts.

## Build

Requirements: Node 22, npm, Chromium, and (for the Reel only) Python 3 and FFmpeg on PATH. Install dependencies from the lockfile. Set `CHROME_PATH` if using a local Chromium; if unset, install Playwright Chromium (`npx --prefix production/payment-check playwright-core install chromium`). The commands below run from the repo root.

```sh
npm ci --prefix production/payment-check
npm --prefix production/payment-check test
npm --prefix production/payment-check run render
```

This creates seven ordered 1080×1350 PNGs, a three-page A4 PDF with live source links, copy and `qa/layout-and-proof.json` under `out/payment-check/`. For another output directory set `PAYMENT_CHECK_OUT` and change the audio output path below accordingly. `render.mjs` resolves local fonts and assets at a synthetic origin. Remote requests, missing fonts, content overflowing slide bounds and overlapping footers fail the build.

## Reel

Use approved Kiswahili audio clips `01.wav` through `04.wav` matching `voice-cues.json` (mono, 16-bit). The draft uses the previously auditioned male Kiswahili TTS voice at 0.92×. No music. Keep clips outside Git; the automated prep scrubs silence, normalizes, aligns SW/EN SRTs against the assembled track, and rejects a Reel ≥25 seconds.

```sh
python3 production/payment-check/prepare-audio.py .cache/payment-check-voice out/payment-check/audio
npm --prefix production/payment-check run reel -- stills
npm --prefix production/payment-check run reel -- video
```

`-- all` (default) renders stills followed by video. The proof card reuses the model output and shows the same receipt reference after the second notification. The PDF preview and worksheet crops are generated by the earlier `render` command. The Maker mark is the [original cleared asset](../../content/assets/README.md). Text and diagram SVG paths are original; Inter, Fraunces and JetBrains Mono are Fontsource packages. There is no screenshot implying Faida/ClickPesa ran the example.

Review opens, scene changes, repeated receipt and keyword at phone size. Probe the MP4 (1080×1920, H.264/yuv420p, 60 fps constant, AAC 48 kHz), decode it fully and check subtitles and peak loudness. Confirm the PDF renders three A4 pages and link targets resolve, package only the approved handoff, then verify the uploaded bytes and owner download capability. Keep the work folder private; a resource link for commenters must be approved and tested separately.
