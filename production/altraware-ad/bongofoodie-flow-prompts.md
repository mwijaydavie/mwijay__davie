## How to run these in Flow

1. Aspect 9:16 / 16:9 in the Flow settings — state it in the prompt too (it is).
2. Optional: attach 2–3 screenshots as **ingredients** only for palette continuity
   (BongoFoodie cream/orange + ink on warm light). Do NOT expect legible UI from Flow.
3. Generate 3–4 takes per clip; the first is a sketch. Change ONE thing per regenerate.
4. Compose in CapCut/editor: screenshots (2 beats each), VO by you (Kiswahili), captions,
   end-card built from brand tokens (cream #FBF7EF, ink #1D2A33, gold #F2C66D, violet #5B3FB5).
5. Muted-phone test: if one burned line isn't readable at arm's length, the editor rebuilds it.

## Honest notes

- These are **starting prompts**, not guaranteed first-take results. Regenerate; timing
  beats (0:02 ping / 0:06 plate) may need nudging by ±0.5 s.
- BongoFoodie UI never renders from Flow — it is always comped from the real screenshots.
- VO must be recorded (Flow speaks English badly at Swahili cadence) — budget 20 minutes.
- Claims in the prompt (revenue today, TSh 92,500) mirror the screenshots you sent — keep
  them only if the live app shows the same; otherwise use generic numbers in the comp.
