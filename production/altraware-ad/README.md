5. **Maandishi yote makubwa ya kwenye §2 yaingizwe upya kwenye editor** — Flow hupiga layout, editor huhakikisha legibility.

## 5. Sauti (audio) — maamuzi muhimu

## 7. Orodha ya kuanza (kwa Flow, mpangilio)

1. Fungua Google Flow → mradi mpya → upload `image-30.png` kama reference
2. Kwenye CLIP 1 prompt (§3) → generate (10s, 9:16) → kama uso au tipografia vipotoka sana, regenerate (mara 2–3 ni kawaida)
3. Rudia CLIP 2, kisha CLIP 3 — CLIP 3 end-card mara nyingi inahitaji 2–3 jaribio (maandishi madogo)
4. Editor (CapCut/Alight Motion): zunganisha CLIP 1→2→3, screen-recordings za Faida/CareTrack, subtitles za Kiswahili, logo/end-card, VO yako, muziki -18dB
5. Export: 1080×1920 H.264, ~30 fps, 6–12 Mbps; na toleo la 16:9 kwa YouTube
6. Weka kwenye: IG Reels / TikTok / YouTube Shorts (9:16) + YouTube (16:9). Link au upload files kwenye Drive na ushiriki timu
